# RIFF character-set samples

These controlled fixtures contain 0.1 seconds of a 440 Hz sine wave: mono,
8000 Hz, signed 16-bit PCM (800 samples). No third-party recording is used.

The audio and initial INFO metadata were created with FFmpeg 8.1.2. The INFO
strings were then transcoded and CSET chunks inserted using a separate fixture
preparation script. These are deliberately prepared fixtures, not unmodified
exports demonstrating a tagging application's CSET behavior. Tests read these
checked-in files directly; the preparation script is not included.

| File | INFO encoding | CSET code page | Location | Title |
| --- | --- | --- | --- | --- |
| cest_latin1-default.wav | ISO-8859-1 | absent | — | Mötley |
| cest_latin1-zero.wav | ISO-8859-1 | 0 | before INFO | Mötley |
| cest_latin1-explicit.wav | ISO-8859-1 | 28591 | before INFO | Mötley |
| cest_windows1252.wav | Windows-1252 | 1252 | before INFO | “Mötley” – 10 € |
| cest_windows1252-after-info.wav | Windows-1252 | 1252 | after INFO and audio | “Mötley” – 10 € |
| cest_utf8-after-info.wav | UTF-8 | 65001 | after INFO and audio | 音楽 – Mötley |
| cest_unsupported1251.wav | Windows-1251 | 1251 | after INFO and audio | Музыка |
| cest_truncated-cset.wav | ISO-8859-1 | truncated structure | after audio | Mötley |

The artist is `Björk`, except in the Windows-1251 sample (`Артист`). INFO values
include their terminating zero; odd-sized values also have RIFF padding. The
Windows-1252 title contains a euro sign and smart quotes to distinguish it from
Latin-1. The malformed sample contains only the code-page WORD instead of all
four required CSET WORDs.

The parser currently supports code pages 28591, 1252 and 65001 (plus default 0).
The Windows-1251 sample verifies that an unsupported declaration produces a
warning and omits INFO metadata without preventing audio properties being read.

References:

- [Microsoft/IBM RIFF specification, CSET (PDF page 25)](https://www.robotplanet.dk/audio/wav_meta_data/riff_mci.pdf#page=25)
- [Microsoft code-page identifiers](https://learn.microsoft.com/en-us/windows/win32/intl/code-page-identifiers)

## Observer timing samples

The following files reuse the PCM audio above. Their ID3v2.3 chunk was copied
from a short MP3 generated by FFmpeg 8.1.2 with title `ID3 observer title` and
artist `ID3 artist`. Chunks were arranged explicitly to exercise stream ordering:

| File | Chunk order after fmt |
| --- | --- |
| cest_id3-before-data.wav | ID3, data |
| cest_info-id3-cset-before-data.wav | INFO (Windows-1252), ID3, CSET (1252), data |
| cest_cset-info-id3-before-data.wav | CSET (1252), INFO (Windows-1252), ID3, data |
| cest_info-id3-no-cset.wav | INFO (Latin-1), ID3, data |
| cest_invalid-id3-before-data.wav | Invalid ID3, data |
| cest_info-invalid-id3-no-cset.wav | INFO (Latin-1), invalid ID3, data |

In the malformed derivatives, the ID3 payload signature was changed from `ID3`
to `BAD`. Tests deliver each file's headers before making its audio available,
checking observer timing and early error reporting without timing-dependent waits.
